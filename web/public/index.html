converting.md
API Syntax

Turn any web page into Markdown

Add converting.md/ before any link in your address bar, or paste the link here.

Markdown to HTML

API

The same conversion works from scripts, agents and the command line.

Address bar

https://converting.md/https://example.com/article

GET

curl "https://converting.md/v1/markdown?url=https%3A%2F%2Fexample.com%2Farticle"

POST with JSON output

curl -X POST "https://converting.md/v1/markdown" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/article", "format": "json"}'
